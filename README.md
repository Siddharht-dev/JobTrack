# JobTrack

JobTrack is a full-stack **Job Application Tracker** built with React, Node.js, Express, and MongoDB.

### Features

* User registration & login
* JWT authentication
* Add, view, edit & delete jobs
* User-specific job applications
* Logout & route protection

### Tech Stack

**Frontend:** React, Vite, Axios, React Router, Tailwind CSS
**Backend:** Node.js, Express.js, JWT, bcryptjs
**Database:** MongoDB, Mongoose

### 🤖 AI Integration

This project was built with the goal of integrating **AI features** into a real-world application. The next phase will add an **AI chatbot** that can interact with JobTrack data and provide useful insights.
